# Madeline Sykes – Personal Website 
### Current Version: v2

Greetings, and welcome.

This site serves as a hub for my writings, along with my engineering artifacts.

## Tech Stack

- **Astro Web Framework** – For the static site (zero client-side JS by default)
- Plain HTML/Markdown for content
- Custom CSS
- GitHub Pages hosting

## v1 to v2: Archival of the Initial Webpage

The first iteration of this site was pure HTML, CSS, and some minimal JavaScript.

As my notebook grew into a substantial collection of essays and I decided to add "Engineering Artifacts," maintaining shared components across dozens of pages became impractical and the scaling was horrendously bad.

I then moved to building the entire thing off Astro, considering a few things I was looking for:
- Great for static sites focused on content
- Built-in Markdown/MDX support with content collections
- Partial hydration through Islands Architecture
